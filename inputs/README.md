# 自行准备的课程资料

- `current/<course_id>/`：同一课程、同一轮次的大纲、教学方案、评分规则及正式成绩单。
- `references/`：有权使用的历史报告，作为字段解释、表格组织和表达的参考。

真实成绩、姓名学号、教师材料、参考报告及扫描件均不随代码发布。除本说明和空目录占位文件外，本目录默认不提交 Git。

`scripts/make_case.py` 初始登记全部材料为 `current`；生成 case 后应按实际用途改为 `rule`、`history`、`style_reference` 等。参考内容不能冒充当前课程事实；特殊成绩状态及阈值须按本课制度核对。缺少关键成绩单时，流程会停止并输出提示。
