# 原阶段实验事实与公开复现边界

截至 2026-11-13，这份代码包从当前项目另行整理。原目录、训练数据、权重和既有报告不随包提供，也不被本包覆盖。

原阶段已在 7 个真实课程包上生成并复核报告，代码测试增至 325 项。这里的测试数量指自动回归测试，不是 325 门课程或 325 次报告验收。最新两门课各有原模型和候选模型版本；表格统一排版后，4 份报告共 86 页、94 图。代码包使用重新构建的公开演示模板，因此不会复现原学校报告的版式逐像素结果。

最新一轮整理了 78 条来源绑定 SFT 任务样本，含真实记录的派生任务及反事实样本；65 条训练、13 条按课程家族留出的开发验证。9 条继承既有人审，其余为用户授权代理核对，不能描述为全部人工标注或独立盲测集。

4-bit QLoRA 从既有 Adapter 继续训练，正式 1 epoch、9 个优化器步，另做独立 5 步 smoke。开发验证 teacher-forced loss 从约 1.3147 降为 1.0827；同输入生成任务的输入约束通过项从 11/13 变为 12/13，JSON 均为 13/13。这些指标不等同于成绩识别准确率、完整报告质量或跨课程泛化。

后续两份成绩识别探针中，原/候选均为 0/2；候选没有推广为现用模型。计算、图表与排版的共同代码修复不计为微调增益。公开包保留这项结论，不夸大实验效果。

本包可以复现代码流程、合成示例计算和微调链路。要复现上述原阶段数值，仍需要相同的私有来源、审核记录、数据划分、基座与起始 Adapter；缺少这些资源时应报告为新的独立实验。

本次代码包整理实际执行的检查见 `validation/RELEASE_VALIDATION.json`，它与上述历史 GPU 训练事实分开记录。本次打包不会再次执行 GPU 正式训练或更换本机服务权重。
